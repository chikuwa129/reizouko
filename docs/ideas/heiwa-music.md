# 荒野ロック平和伝（仮）企画メモ

（旧題：平和音楽事務所）

**音楽の力で世界を平和にする経営シミュレーション**。ほかの企画（怪獣育成・地球さら地化）とは一切切り離す。

## 方向性
- 経営型。カイロソフトのゲームのような「スタッフを雇って育てる → 組み合わせで作品を作る → 相性を見つけていく → 施設を強化する → 年末の賞」という**ジャンルの仕組み**を借りる（名前・絵柄・特定作品の再現はしない）
- トーンはシュールなコメディ。争いの理由がしょうもない（カレーの辛さ、ピザのパイナップル、きのことたけのこ）
- 世界地図を「緊張 → 平和」で塗っていく

## 世界観（決定・2回目の打ち合わせ）
- **荒廃した地球**。文明が崩れたあとの荒野で、娯楽もなく、争いばかりが起きている（世紀末もののジャンル。特定作品の名前・キャラ・絵は使わない）
- 主人公は**モヒカンのザコ**。ある日ロックに目覚め、ギターを片手に世界平和を目指して音楽を作る
- 音楽で**屈服させた／感銘を受けた**やつらが仲間になる。バンドメンバーになったり、スタッフになったりして、最終的に世界を平和にする

### 世界観をシステムに落とすと（案）
- **地域＝荒野の縄張り**。それぞれを仕切るボス（暴走族の頭、水を独占する砦の主、鉄くず王国の王など）がいる。「緊張」は「殺気」
- **仲間はスカウトではなくライブで手に入る**。縄張りの殺気をゼロにすると、ボスや手下が仲間になる。元の得意分野がそのまま役割になる
  - 例：太鼓で合図していた暴走族の頭 → ドラム／火炎放射器使い → 照明スタッフ／水を売っていた商人 → マネージャー／鉄くず加工屋 → 楽器職人／改造バギー乗り → ツアーの運転手
- **ライブはボスとの音楽バトル**：ボスの「暴力」に「ノリ」で勝つと屈服する
- **楽器は廃材から作る**：ドラム缶ドラム、鉄パイプギター。楽器職人を仲間にすると良い楽器が作れる
- **お金のかわりに物資**：水・ガソリン・缶詰で回す
- **ジャンルは「発掘」する**：音楽が失われた世界なので、廃墟でカセットテープを見つけるとジャンルを思い出す
- **施設は廃墟を改造**：廃ガソリンスタンドのスタジオ、ライブに要る発電機、給水塔
- **ラスボス**：音楽を禁止した荒野の王。最後は世界初の大フェスで決着

## 試作版 v1（prototype/heiwa/index.html・世界観を決める前のもの）
- 時間は自動で進む（1週ずつ。停止・1倍・2倍・4倍）。5年（240週）以内に世界の平和度90%が目標
- **曲づくり**：ジャンル×テーマを選んで、メンバー全員で4週かけて作る。メンバーの頭上に「メロディ（ピンク）」「ノリ（オレンジ）」の数字が飛ぶ
  - ジャンルごとにメロディ重視・ノリ重視が違う
  - ジャンル×テーマの相性（◎○△×）は作ってみるまでわからない。見つけると「相性◎発見！」
  - 曲の力でS〜Dランク
- **リリース**：作った曲は自動で発売。数か月売れ続けてお金とファンになり、世界中のラジオで流れて少しずつ緊張を下げる
- **ツアー**：地図で行き先を選び、手持ちの曲を持ってライブ。到着するとライブの演出
  - 地域ごとに好きなジャンル・苦手なジャンルがある
  - 同じ曲を同じ地域でやると聞き飽きられる
  - 激しい曲（ロック・メタル・EDMなど）はよく効くが、緊張が高い地域では暴動の危険（リスクとリターン）
  - 子守唄は緊張が高い地域ほど効く。兵士が寝る
  - 初めてライブした地域の音楽ジャンルを覚える（演歌・EDM・ダンス歌謡・メタル・クラシック・民族音楽・ヒップホップ・ラテン・レゲエ）
- **新ジャンル誕生**（組み合わせ）：同じ2ジャンルで2曲ずつ作ると融合ジャンルが生まれる。演歌メタル、交響EDM、民族ラップ、子守唄メタル、ラテン演歌。どの地域でも好かれる
- **メンバー**：最大4人。パート（ボーカル・ギター・ベース・ドラム・キーボード・DJ）で能力の傾向が違う。作曲・演奏・歌・華の4能力。仕事でレベルアップ、特訓で能力アップ。スカウト候補は2か月ごとに入れ替わる
- **施設**：スタジオ（制作が速い）、宣伝部（売上）、ツアーバス（移動が速く安い）、練習室（特訓の伸び）
- **世界平和音楽大賞**：年末にその年の最高の曲がAランク以上なら受賞。賞金と全世界の緊張 -3
- 毎月、どこかでまた揉めごとが起きて緊張が上がる。給料は毎月かかる。資金が -300万を下回ると解散
- エンディング：世界平和／だいたい平和／争いは続く／事務所解散

## これから考えたいこと
- ラスボス：音痴の独裁者（歌が下手なのを気にしていただけ）
- 兵器を楽器に改造（戦車の砲身をトロンボーンに）

## 追加アイデア（3回目）
- **仲間の枠は固定**。枠からあふれた仲間や、感銘を受けて増えた信者は、勝手にバンドを組んで**自分たちの前座**になる
- **ステージの規模が上がっていく**：路上 → 廃墟ステージ → 野外ライブ → 荒野フェス
- **2daysフェス**：1日目は前座全員とみんなで、2日目は自分たちだけ
- **ボス戦はライブ**：暴れるボス勢力がステージに押し寄せ、ファンがライブスタッフ（警備）として押しとどめる。1曲やり終わるまで持ちこたえられるかの押し合い
- **警備スタッフは路上ライブで増える**：行動ターンで近くの縄張りで地道に路上ライブをして仲間を増やす

## 試作版 v2（prototype/heiwa/index.html・荒野ロック平和伝）
- 荒野の地図：ガソスタ跡（ねぐら）から道でつながった縄張りへ。解放した縄張りのとなりにだけ行ける。最後は荒野の王都
- 縄張りとボス：鉄くず谷（ガラクタ王→楽器職人）、爆走荒野（爆走のジン→ドラム、舎弟→運転手）、水の砦（砦の女王レイラ→マネージャー）、火炎峡谷（火炎のボンバ→照明）、毒沼の村（祈祷師ヌマ→キーボード）、廃病院（鬼看護長→トレーナー）、地下闘技場（王者ゴウ→ベース）、荒野の王都（荒野の王：音痴を笑われるのが怖くて音楽を禁止していた）
- 枠：バンド4人（あなた＋相棒のザコ＋2人）、スタッフ3人。あふれると「誰と入れかえるか／自分のバンドを組んでもらうか」を選ぶ。外れた方は前座バンドになる
- 信者が一定数を超えるたびに、信者たちが勝手にバンドを組む（モヒカンブラザーズ、ドラム缶ボーイズ…）。前座バンドは勝手に近くの縄張りを回って殺気を下げる
- **ボス戦（殴り込みライブ）**：曲が流れている約9秒のあいだ、ボスの手下がステージに押し寄せ、黄色い「STAFF」の警備スタッフが押しとどめる。「あおる！」ボタンで押し返せる。最後まで演りきると殺気が大きく下がる（守りきるほど効く）。押し込まれるとステージ崩壊でライブ中断、警備スタッフが1人ケガで離脱
  - 激しい曲は効くが相手も熱くなる。子守唄は相手がだんだん眠くなる
- **路上ライブ**：1週・物資2。警備スタッフが2〜4人増え、信者も増える
- ジャンルはカセットテープの発掘（縄張りを解放すると見つかる）。融合ジャンル：演歌メタル、パンク民謡、子守唄メタル、ゴスペルロック、演歌ラップ
- お金のかわりに物資。拠点：ガレージスタジオ、発電機、給水塔、ステージの規模
- 4年（192週）以内に王都を解放すれば勝ち

## 決定（4回目）
- 水の砦のボスは婆ではなく、**アマゾネス風の見た目のいい女戦士「砦の女王レイラ」**にする（婆だとモチベーションが下がる）
- 主人公たちはモブっぽい見た目でいい。客もモヒカンのモブ
- **仲間にするかどうかは選べるが、入れ替えはできない**。メンバーがコロコロ変わるバンドは嫌だし、同じメンバーでやっていくほうが愛着が湧く
  - 仲間にしなかったボスや、枠がいっぱいで入れなかったボスは、自分のバンドを組んで前座になる

## 決定（5回目）
- 仲間にしなかったボスに「前座を頼む」はしない。その場では「また会おう」と去っていくだけ
  - その後は**噂**だけが流れる（「○○が最近、楽器を手にしているらしい」「荒野のどこかで新しいバンドが生まれたらしい」）
  - **荒野フェスの開催を決めたとき**、ステージに見覚えのあるシルエットが現れて「待ちな！ フェスをやるなら俺たちも混ぜてもらうぜ」→ 明かりがつくと「お前らは…！」。倒した連中がバンドを組んでいた、という見せ場にする
  - それまでの前座の仕組みはなくし、ステージの規模はライブの効果アップにした
- **バンドは入れ替えなし、スタッフは入れ替えあり**。スタッフはどんどん強くしていきたいので交代できる。交代で外れたスタッフはファンとして客席に見に来る（ライブの客席に♥つきで出てくる）

## 決定（6回目）
- キャラクターは**漫画タッチ**：黒い主線、大きな目とハイライト、太い眉、トゲトゲの髪。表情を切り替える（ふつう／怒り／笑顔／泣き／眠り）
  - ボスは戦闘中は怒り顔、解放されると泣き顔。客のモヒカンは暴れているときは怒り顔、ノッているときは笑顔、子守唄では寝顔
