# 地球さら地化計画（仮）企画メモ

怪獣育成とは**まったく別の企画**。

## コンセプト
- 悪の親玉（悪の組織でも何でもいい。怪獣でなくてもいい）になって、**あらゆる手を使って地球をさら地にする**
- 手段は隕石、兵器、気候、地殻、侵略、からめ手など何でもあり
- **研究ツリー（スキルツリー）**を進めるほど、できることの規模が上がっていく

## 2部構成
- **前半：ぶっ壊す** … 研究を進めながら地球をさら地にしていく
- **後半：作り直す** … さら地にした地球に、自分たちが住みやすい世界を作る
- 前半の壊し方が、そのまま後半のスタート条件になる
- 後半まで作り込めない場合は、まずエンディング分岐だけで成立させる

## 壊し方と「あと」の違い
| 手段 | 更地にする力 | あとの土地 |
|---|---|---|
| 核・兵器の乱発 | すごく強い | 汚染されて当分住めない |
| 隕石 | 強い | クレーターだらけ。でも資源（鉱石）が手に入る |
| 氷河期 | じわじわ効く | 解けたら案外きれいに使える |
| 火山・地殻 | 強い | 土地は荒れるが、灰で肥沃になる |
| 怪獣 | 中くらい | 瓦礫は多いが環境は無事。怪獣はペットとして残る |
| からめ手（人類を眠らせるなど） | 弱い | 建物がまるごと残るので、そのまま使える |

悩みどころ：
- 早く壊したいが、雑に壊すとあとが大変
- きれいに壊すと時間がかかり、人類やヒーローに対策される
- 地域ごとに壊し方を変える（住む用はきれいに、資源用は隕石で）

## 研究ツリー（スキルツリー）
研究を続けると、手段ごとに「できるレベル」が段階的に上がる。

### 系統の例
- **宇宙系**：小石を落とす → 隕石の軌道を変える → 小惑星を引っぱってくる → 月を落とす
- **兵器系**：爆弾 → ミサイル → 核 → 惑星破壊砲（強いが汚染も最大）
- **気候系**：局地的な大雨 → 異常気象 → 氷河期 → 太陽をいじる
- **地殻系**：地震 → 火山の噴火 → 大陸を割る → 地軸をずらす
- **生物系**：巨大な虫 → 怪獣 → 怪獣軍団 → 生態系を丸ごと書き換える
- **からめ手系**：ネットを止める → 人類をだらけさせる → 全員を眠らせる → 人類をよその星へ引っ越させる

### ツリーの遊び
- 研究には予算・人員・時間が要る。全部は取れないので、**どの系統を伸ばすかが戦略**になる
- 系統をまたぐ**合わせ技**（例：宇宙系＋気候系で「隕石で粉じんを巻き上げて氷河期」）
- 研究の段階が上がるほど派手で強力。ただし強いものほど後の土地を汚しやすい
- **「きれいに壊す」系の研究**（汚染除去、建物だけ消す、など）も用意して、後半に効かせる
- 人類側も研究を進めてくる（迎撃ミサイル、防衛ドーム、ヒーロー）。同じ手を使い続けると通じなくなる

## 人類の対抗
- 手段ごとに人類が学習して対策してくる
- 地球の「さら地率」を地図で見せる。地域ごとに塗りつぶされていく

## 部下
- 幹部・戦闘員・怪獣・マッドサイエンティスト。得意な系統が違う
- 部下によって伸ばしやすい研究ツリーが変わる

## トーンの候補
- 大真面目な悪の組織もの（作戦会議、失敗した幹部の処分など、悪の組織あるあるのシュールな笑い）

## エンディング候補
- 汚染しまくった → 「さら地にはなった。でも誰も住めない」
- きれいに壊した → 自分たちの楽園ができる
- 建物を残しすぎた → 「結局、人類の家に住んでるだけ」
- さら地にした理由がしょうもない（家を建てたかった、など）

## 研究ツリーの方向性（追記）
- イメージはシヴィライゼーションのテクノロジーツリー
- ただし原始からは始めない。**最初からある程度のことはできる**状態でスタート
- 研究が進むと、**別系統のできることが組み合わさって新しい手段になる**（合わせ技ノード）
  - 例：隕石誘導（宇宙）＋気象操作（気候）→ 粉じん氷河期
  - 例：怪獣（生物）＋地震（地殻）→ 地底怪獣で大陸を割る
  - 例：催眠電波（からめ手）＋ミサイル（兵器）→ 人類に自分たちの兵器を撃たせる
- 悪の組織の科学水準は未定。候補：
  - 現代＋α の秘密結社（最初は小規模なテロ程度から）
  - 超科学を持つ宇宙人だが、地球では設備や予算が足りず、一から組み直し
  - 昭和特撮風のマッドサイエンス（理屈はゆるく、何でもあり）
