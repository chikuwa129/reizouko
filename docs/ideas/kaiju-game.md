# 怪獣育成ゲーム 企画メモ（仮）

> ステータス：アイデア段階（まだ作らない）
> 着想：通勤中に「電車をヌンチャクにしたら強そう」と思いついたところから

## コンセプト

**ずんぐりした不器用な怪獣が、真面目に筋トレしながら街を壊し、最後はヒーローに倒される。実はすべて昭和風の特撮番組だった。**

- ジャンル：育成 × 破壊 × 特撮番組の制作シミュレーション
- トーン：シュールで可愛い、ストレス解消系
- 軸：「ゆるい怪獣 × 真面目な人間社会 × 膨らみ続ける請求書」

---

## 1. トレーニング

街のインフラを、**形や使い方に自然に合う器具**として使う。スケールは大きめに（1回の動作で街が1つ変わるくらい）。

| トレーニング | 使うもの | 成功 | 失敗（被害拡大） |
|---|---|---|---|
| ヌンチャク | 電車 | 技術アップ | すっぽ抜けて隣の県まで飛んでいく |
| 縄跳び | 電線 | 持久力アップ | 足に絡まって転び、変電所に倒れ込んで県全体が停電 |
| 水泳 | ダム湖 | 持久力アップ | 壁を蹴ってターンしたらダムが決壊。下流の街が水没 |
| ランニング | 高速道路 | 素早さアップ | 転倒してジャンクションが全部潰れる |
| 懸垂 | 電波塔 | 腕力アップ | 塔が折れてテレビ放送が全局止まる |
| ベンチプレス | 新幹線の高架 | 腕力アップ | 潰れて自分の上に落ちる。線路も全損 |
| サウナ | 火力発電所 | 耐熱性アップ | 長居しすぎて発電所ごとのぼせる。爆発 |
| 水切り | コンテナ船 | 投てき力アップ | 跳ねすぎて対岸の港に突っ込む |

### 失敗と連鎖
- 各トレーニングはタイミングや連打のミニゲーム。ミスると失敗演出へ
- **疲労度が溜まるほど失敗しやすい**。休まず続けると連続失敗で被害が雪だるま式に増える
- 失敗すると能力の伸びは小さいが、被害額は成功時の数倍
- 「強く育てる」か「わざと失敗して被害額を稼ぐ」かのジレンマ
- 被害は連鎖する：ダム決壊 → 下流の発電所が浸水 → 停電 → 電車が止まり通勤客が街にあふれる

## 2. 食事

食べた物は能力を上げるだけでなく**体内に蓄積**し、倒されたときに中身に応じた被害が出る。危ない物ほどハイリスク・ハイリターン。

| 食べ物 | 育成効果 | 倒されたときの被害 |
|---|---|---|
| 石油（タンカー、コンビナート） | 火力、炎を吐ける | 大爆発と大炎上。湾岸一帯が数週間燃える |
| ウラン（原発） | 全能力が大きく上がる | 立入禁止区域（被害額が桁違い） |
| 電気（送電線、変電所） | 素早さ、放電 | 広範囲が長期間停電 |
| 化学工場 | 毒の息 | 有毒ガスで避難区域が広がる |
| 金塊（中央銀行の金庫） | 防御力 | 金が飛び散って市場が大混乱 |
| ゴミ処理場 | 再生能力 | 悪臭が数年残る |
| ビール工場 | 機嫌が良くなる | 一帯が泡まみれ |
| 人工衛星 | 宇宙適性 | 破片が世界中に落ちる |
| 冷凍倉庫 | 耐熱性 | 大量のマグロが空から降る |

- 組み合わせで反応（石油 × 電気で爆発の威力アップ など）
- 倒される場所でも被害が変わる（海上なら安く、都心なら最悪）

## 3. 被害額

- 画面に被害額カウンターを常時表示（円で細かく積み上がる）
- ニュースのテロップで明細を流す：「〇〇線 全線運休 / 損失 42億円」
- 人間側の反応が段階的に大きくなる：記者会見 → 対策本部 → 国際会議 → ヒーロー召喚
- **トーンは大真面目**。可愛い怪獣との温度差でシュールさを出す
  - 例：「専門家の解説：怪獣は水泳の際、ターンの壁の強度を考慮していなかった模様」
- リザルトは請求書・決算書の形式。「生前の損害」より「死後の損害」のほうが大きいのがポイント
- 後日談：死体の解体費用の請求 → 観光地化して怪獣まんじゅうの売上で少し戻る

## 4. ヒーロー戦

- 基本は勝てない前提。どれだけ粘れたか、散り方、最期の被害が評価される
- ヒーローはやたら真剣、怪獣は最後まできょとんとしたまま
- ヒーローはオリジナルデザインにする（元ネタが分かりすぎない範囲で）

## 5. オチ：実は特撮番組

1. 必殺技で怪獣が倒れ、大爆発
2. カメラが引くと撮影スタジオのセット。監督が「カット！」
3. 着ぐるみの頭が外れ、中の人が水を飲んでいる
4. 番組のクレジット風エンドロール
5. 最後に**本当の制作費の請求書**：「ミニチュア制作費 3,200万円」「火薬代 800万円」「着ぐるみのクリーニング代 12万円」
   - 劇中の被害は何兆円なのに、本当の請求は数千万円というギャップ
   - 壊しすぎると「セット作り直しで制作費オーバー、プロデューサー激怒」

### 伏線
- たまに映り込むピアノ線やスタッフの影
- 壊れたビルの断面が発泡スチロール
- 電車の車輪が鉄道模型そのもの

## 6. 周回：番組のシリーズ化

- **1周 = 番組の1話分**。視聴率がスコア
- シリーズが続くほど予算が増え、セットが豪華に（壊せる物が増える）
- 視聴率次第で打ち切り or 延長。延長すると映画化（大規模セットを丸ごと壊す回）
- 打ち切りなら最終回は「怪獣たち、宇宙へ帰る」のゆるい締め

### 引き継ぎ：着ぐるみ改造（昭和特撮オマージュ）
- 前の周回の怪獣の**シルエットはそのまま**、パーツを足して新怪獣として登場
- パーツは前の周回の内容で解放
  - 石油をたくさん食べた → 背中に煙突
  - 電線縄跳びを極めた → しっぽが電線のように伸びる
  - ダムを壊した → ヒレが付いて水棲型
- 改造を重ねるほどつぎはぎ感が出る（「よく見ると第1話の怪獣」）
- 予算が少ないと改造パーツがダンボール製

### 人気と再登場
- 視聴率・人気（ファンレターなど）が高いと同じ怪獣が「二代目」「強化版」として再登場
- 人気が高すぎるとソフビ人形が売れ、売上が番組予算に入る
- 人気がないと、次の話でほかの怪獣の引き立て役として一瞬で倒される

### ヒーローを倒してしまったら
脚本が変わり、相手が入れ替わる：
1. 人間の防衛隊（戦車・戦闘機。ほぼ食べ物扱い）
2. 人間が作った巨大ロボット（ロボットも不器用で被害倍増）
3. 2号ヒーロー（「新ヒーロー登場！」特別編。初代より強い）
4. 怪獣同士の対決（過去の周回で作った自分の怪獣と戦う）

- 「強く育てる」「派手に壊す」「人気を出す」のバランスで番組の運命が変わる

## 見た目・雰囲気

- **昭和特撮風のジオラマ**。ティルトシフトで常にミニチュア感
- 怪獣：二足歩行・背びれ・しっぽの王道シルエット。頭大きめ、手足短めでずんぐり。目は小さく丸く、表情少なめ
  - 実在の怪獣に寄せすぎず、顔・背びれ・色はオリジナルにする
- 動きは着ぐるみっぽく少しぎこちない。失敗時に一瞬だけ「あ」の顔
- 鳴き声は間の抜けた音（「ぼえ〜」）
- 被害描写にグロや悲惨さは出さない。人は小さくワーッと逃げるだけ、建物はおもちゃっぽく崩れる
- 壊れる音はコミカル（ポコッ、ガラガラ、ぷしゅー）。ただし音と揺れの気持ちよさは作り込む
- 水はゼリーっぽく、炎は作り物っぽく。わざとセット感を残す
- 小ネタ：トレーニング日誌が淡々としている（「きょうは ダムで およいだ。みずが へった。」）、SNSトレンド欄（「#怪獣 縄跳び うますぎ」「電車返して」）

## 追加アイデア（2回目）

### 番組の構成
- 期間は**1クール分**（全13話くらい）
- クール終了後の分岐：**延長** / **続編** / **人間側が作った怪獣を倒す展開**
- タイトルは最初「怪獣育成（仮）」のような**企画書風** → 第1話が終わると**番組タイトル**に変わる

### 怪獣のバリエーション
- **素体は4体**くらい
- 各素体から**派生は3体分**くらいまで（着ぐるみ改造）
- ラスト（最終回）の候補：**今までの怪獣のごちゃ混ぜ**、または**今まで怪獣に指示していた親玉**

### 倒した相手の再利用
- ヒーローやロボットを倒せたら、それを利用した**ニセヒーロー**や**メカ怪獣**が登場する

### 画面
- **横画面**用。テレビ番組風の仕掛けのため（画面比は気にしない）

### 人気の補正
- **ヒーロー人気**か**怪獣人気**かで補正がかかる

### 動かない回
- 怪獣が寝て動かない場合などは、**総集編**や**内部回**（人間側のドラマ回）になる

### 行動の見せ方
- 育成中は**行動名だけ**表示し、**何で何をしたかは後から分かる**ようにする
  - 例：「ヌンチャク」とだけ出て、後のニュースで電車を使っていたと分かる

### 行動の回数制限と街への反映
- 同じ行動を一定回数繰り返すと**できなくなる**
  - 例：電車でヌンチャクを続けると「ヌンチャクにする電車がもうない…」
- 怪獣の行動の結果が街に残り、次の行動に反映される（連鎖要素と合わせる）

## 桜井流チェック（sakurai-skill より）

[kociden/sakurai-skill](https://github.com/kociden/sakurai-skill)（「桜井政博のゲーム作るには」の要約。非公式・AI要約なので、正確には元動画を参照）の原則を、この企画に当てたメモ。#番号は動画の通し番号。

### 良い点（伸ばす）
- **リスクとリターンが近い位置にある**（#006）：無理して鍛えるほど強くなるが失敗すると被害が膨らむ。危ない物を食べるほど強いが、最期の被害も増える。この企画の核はここ
- **被害総額スコアは原則そのもの**（#198）：スコアを現実の尺度に置き換える好例として被害総額が挙がっている。円で素早くカウントアップする気持ちよさまで仕様として作り込む
- **負けて終わる構造**（#097）：倒されるのがスッキリする娯楽として成立しうる。勝っても負けても面白い状態を目指す
- **ズルを許す**（#048）：わざと失敗して被害額を稼ぐ、寝続けて総集編を連発する、などは潰さず、ネタとして反応を用意する（「今週も総集編」で苦情殺到など）
- **長所も短所も伸ばす**（#245）：ヒーロー人気・怪獣人気の補正は平均に寄せず、両極に大きく振れるようにする

### 気をつけたい点（直す案つき）
- **最初の3分で面白さを伝える**（#017）／**チュートリアルは本編の形で**（#085）
  → 企画書風タイトルの演出は短く。第1話の冒頭からすぐ街に降りて電車ヌンチャクをさせ、第1話をそのまま練習回にする
- **ご褒美は真っ先に決める**（#075）／**目の前に吊るす**（#023）
  → 「次の改造パーツまで被害あと○億円」「打ち切りラインまで視聴率あと○%」を常に表示する
- **押して何も起きない状態を作らない**（#104）
  → 「行動名だけ表示」でも、選んだ瞬間に地響き・遠くの爆発音・テロップ1行などの反応は必ず出す。詳細の種明かしだけを後に回す
- **詰んで先に進めないのが最悪**（2章）／**先を見たい動機を見せ続ける**（#127）
  → 回数制限で行動ができなくなったら、代わりの行動を解放する（電車がない → 別の物でヌンチャク）。「街が変わっていく景色」を変化として見せる
- **遅さは罪**（4章）
  → 総集編・内部回は短く、スキップ可能に。そのうえで疲労回復や人気の変動など、何か得る物を付ける
- **強さを一直線の坂にしない**（#105）
  → 1クールの中に山場を交互に置く（例：第4話でロボット回、第8話で2号ヒーロー、第13話で最終回）
- **続編ははっきりパワーアップさせる**（#162）
  → 続編ルートでは予算増、新しい素体、大きなセットなど、目に見える変化を用意する
- **企画書にA案もB案も書かない**（#109）
  → 「延長／続編」「ごちゃ混ぜ／親玉」のうち、**プレイ結果で分岐するもの**はそのまま残してよい。**作り手が決めていないだけのもの**は、作る前に一つに決める

### 作る前に決めること
- ~~最終回の相手は、プレイ結果で分岐させるか、どちらか一つに決めるか~~ → **分岐に決定**（下の「最終回の分岐」参照）
- 素体4体それぞれの特徴を一言で言えるようにする（#204 キャラは尖らせる）
- 1クール13話の中で、どの話数に山場を置くか

## 最終回の分岐（決定）

- 最終回は**それまでの成果（被害額・視聴率）と人気（怪獣人気・ヒーロー人気）で分岐**する
  - 例：怪獣人気が高い → 今までの怪獣のごちゃ混ぜが登場して大暴れ
  - 例：成果が大きい → 裏で指示していた親玉が姿を現す

### 親玉がヒーローに勝った場合
- プレイヤー（怪獣側）としては**成功**。でも番組としては**バッドエンド**
- このねじれをそのまま演出にする
  - 最終回はヒーローが倒れたまま、エンドロールが無音で流れる
  - 放送後、視聴者からの苦情とSNSの大荒れ（「子どもが泣いた」「ヒーローを返して」）
  - でも視聴率は過去最高 → 制作会社は大喜び
- 続編ではなく、**第1話から人間側でやり直すプレイ**が始まる（下の「人間側プレイ」参照）
- 一方で、ヒーローが勝つ王道ルートでは「平和が戻った」きれいな最終回 → 延長や続編はおだやかなスタートになる
- つまり**勝ちすぎると次がハードモードになる**。プレイヤーが自分で難易度を選んでいる形になり、リスクとリターンの原則にも合う

## 人間側プレイ（第1話からやり直し）

親玉がヒーローに勝ってバッドエンドになったときに解放される、**同じ1クールを第1話から人間側でやり直す**モード。続編ではなく、同じ物語の裏側。

### 基本の形
- プレイヤーは防衛隊・科学者・市民などを操作する
- 怪獣は**自分が怪獣側で遊んだときの行動をそのまま再現**して動く（自分のプレイの記録が敵になる）
- 怪獣側では「ヌンチャク」と行動名しか見えなかったものが、人間側では**電車が持ち去られる現場**として目の前で起きる。前半の伏せていた部分の答え合わせになる

### 人間側でやること
- 避難誘導や、壊されそうな物を先に守る・移す（電車を車庫に隠す、ダムの水位を下げておく など）
- 被害を減らして、最終回に向けた**人間側の手札**を残す
  - 電車が残っている → 防衛隊が現場に急行できる
  - 発電所が無事 → 新兵器を動かす電力がある
- ヒーロー人気を上げて、**奇跡の条件**をそろえる

### 最終回
- 人間の力だけで親玉は倒せない。目的は**奇跡が起きるまで持ちこたえる**か、**奇跡の条件をそろえる**こと
- 奇跡の例（何でもアリ。特撮のお約束を逆手に取る）
  - 突然不思議な事が起こり、ヒーローが復活する
  - 宇宙から**兄貴分のヒーロー**が助けに来る（オリジナルデザイン）
  - 子どもたちの応援でヒーローが立ち上がる
  - 科学者が徹夜で作った新兵器がギリギリ間に合う
- どの奇跡が起きるかは、人間側プレイで積み上げたヒーロー人気と残った手札で決まる
- 成功すればヒーロー勝利の大団円。失敗すると本当のバッドエンド（それもエンディングの一つとして収集できる）

### ポイント
- **怪獣側で好き放題やったツケを、自分で払う**。被害額の重みがここで効いてくる
- 怪獣側で派手にやるほど人間側は難しくなる。両方を遊ぶと、1本のクールが表と裏で完成する
- 怪獣の行動が決まっているので、人間側は**先読みして備える**パズル寄りの遊びになり、怪獣側の爽快さと手触りが変わる

## 追加アイデア（3回目）

### 破壊のスケール
- 最終的には**地球が更地になるくらい**暴れられるようにしたい

### 出現場所の移動
- 暴れるほどその場所で**できることがなくなる**（電車を使い切る、ダムがなくなる など）
- できることがなくなると、**怪獣の出現場所が変わる**（都市 → 港 → 山間部 → 海外 → …）
- 出現場所が変わると**できる行動が変わり**、怪獣の**特色も変わっていく**
  - 例：都市で暴れ尽くした → 港へ移動 → 船や海を使う行動が中心になり、水棲寄りに育つ
- 回数制限・連鎖要素と合わせて、「街が変わっていく」ことがそのままステージ進行になる
- 地球が更地になるまで、出現場所を渡り歩いていくイメージ

### 最終回のごちゃ混ぜ怪獣
- イメージは**昭和特撮の合体怪獣**（過去の怪獣のパーツを寄せ集めた怪獣。例：タイラント）。デザインはオリジナルにする
- **素体4体がそれぞれパーツになる**（例：頭・腕・胴・脚／しっぽ）
- → これで**素体ごとの特色をどの部位に持たせるか**が決まる
  - 例：腕担当の素体は投げ・振り回し系、脚担当の素体は走る・跳ぶ系
- 素体の特徴を決めるときは、「どの部位になるか」から逆算する

### 合体怪獣とニセヒーローの両立（要調整）
合体怪獣（素体4体のパーツ）と、倒したヒーローを利用するニセヒーローが相反しないように、うまく組み合わせる。案：

- **ヒーローの技だけ取り込む**：ヒーロー本体はパーツにせず、必殺技（光線など）だけを合体怪獣が使えるようにする。見た目は怪獣のまま、技だけヒーロー
- **弱点を引き継ぐ**：取り込んだ技と一緒に、ヒーロー側の弱点（時間制限、特定の攻撃に弱い など）も引き継ぐ。強さとリスクがセットになる
- **特効**：ヒーローの力を取り込んでいると、**2号ヒーローや兄貴分ヒーローの攻撃が特によく効く**（「同じ光の力だから通る」）。人間側プレイの奇跡とも噛み合う
- **ルートで出し分ける**：ヒーローを倒したクールではニセヒーロー回を中盤に置き、最終回は合体怪獣。ニセヒーロー回で手に入れた技が、最終回の合体怪獣に引き継がれる、という流れにすると両方生きる

### 1話の進行と人間側との遭遇（後で細かく決める）
- 怪獣の行動は**1話につき朝・昼・晩の3ターン**のイメージ
- 各ターンで行動（トレーニング・食事・休むなど）を1つ選ぶ
- **いつ人間側（防衛隊・ヒーロー）とぶつかるか**は、次の要素で決まる
  - **被害状況**：被害が大きいほど人間側の警戒が強まり、見つかりやすい
  - **怪獣のステルス特性**：素体や改造パーツによって見つかりにくさが違う（例：水棲型は海に潜れる、夜行性は晩に強い）
- 考えられる仕組みの例
  - 人間側の**警戒度ゲージ**を置き、行動ごとに上下させる。一定を超えるとその話のうちに迎撃が来る
  - 時間帯で見つかりやすさが変わる（朝は通勤客に目撃されやすい、晩は暗くて見つかりにくい など）
  - 見つかる前に派手な行動をしておくか、こっそり育てて終盤に一気に暴れるか、の駆け引き
- 人間側プレイでは、同じ朝・昼・晩の流れの中で、怪獣の動きを先読みして備える

### 操作UI

  - 体力が減ると**失敗率**が上がり、選ぶ前に分かる → 失敗と被害拡大の仕組みとそのまま対応する
  - ターンの合間に**イベント**が入る（ニュース、人間側の動き、謎の親玉からの指示など）
  - 行動結果は短い演出 + 数値の上昇で、テンポよく次へ
- **場面転換**で、怪獣が実際に動いて街が壊れていく情景を挟む

  - 短く・スキップ可能に（テンポ優先）。ターンごとは数秒、話の終わりに少し長めのダイジェスト
- 場面転換の**枠組み（見せ方）が、人間側に見つかっているかどうかで変わる**
  - **見つかっていない**：引きの絵・シルエット中心。遠くで何かが起きている感じ（例：防犯カメラ風、目撃者のスマホ映像風、ノイズ混じり）
  - **見つかっている**：**ニュース中継風**。ヘリからの空撮、「LIVE」表示、テロップ、被害額の速報、キャスターの実況
  - 警戒度が上がるほど、枠が「うわさ → 目撃情報 → 速報 → 特番」と大げさになっていく
  - 枠の変化そのものが、今どれくらい警戒されているかを伝えるUIになる

### 素体の参考
- **昭和特撮の怪獣（およびそのリメイク怪獣）**と、**合体怪獣（タイラント）のモチーフの組み合わせ方**を参考にする
- 参考にするのは**型（アーキタイプ）**と組み合わせの考え方まで。個別の怪獣の名前・顔・デザインはそのまま使わず、オリジナルにする
- 昭和怪獣によくある型の例（ここから4体を選ぶ叩き台）
  - 恐竜・爬虫類型（王道。二足歩行、しっぽ）
  - 甲殻類・昆虫型（ハサミ、硬い殻、多脚）
  - 鳥・飛行型（翼、空から来る）
  - 水棲・海獣型（ヒレ、海や湖に潜む）
  - 宇宙・異形型（左右非対称、光る器官）
  - 鉱物・機械型（硬い、重い）
- 合体怪獣を前提に、素体ごとに**担当部位**を決めておく（例：恐竜型 → 頭と胴、甲殻類型 → 腕、鳥型 → 背中・翼、水棲型 → 脚・しっぽ）
- 担当部位・得意な行動・出現場所・ステルス特性をセットで決めると、育成と最終回がつながる

### 素体（仮決定）
- 通常の素体は **恐竜・鳥・水棲・鉱物** の4体
- 担当部位の叩き台（合体怪獣のパーツ）
  | 素体 | 担当部位 | 得意そうな行動 | 出現しやすい場所 | ステルス |
  |---|---|---|---|---|
  | 恐竜 | 頭 | 炎・咆哮、王道の破壊 | 都市 | 低い（目立つ） |
  | 鳥 | 腕・翼 | 投げる・運ぶ、空中移動 | 山・空港 | 中（空に逃げられる） |
  | 水棲 | 脚・しっぽ | 泳ぐ・薙ぎ払う | 港・ダム・海 | 高い（潜れる） |
  | 鉱物 | 胴 | 持ち上げる・耐える、資源を食べる | 鉱山・工業地帯 | 中（岩に擬態） |
- **宇宙型はレア枠**
  - 出現が珍しく、**とても強い**。昭和特撮の「最強クラスの宇宙怪獣」のような立ち位置（デザインはオリジナル）
  - **親玉の正体が宇宙型**（決定）。今まで怪獣たちに指示していた黒幕が、最終回で最強の宇宙怪獣として姿を現す

## 1クール（全13話）の構成案

### 実際の特撮番組でよくある型（参考）
- **第1話**：怪獣とヒーローの初登場。いきなり街で暴れて、いきなり対決する
- **前後編**：強敵回や、ヒーローが一度負ける回は前後編にして引きを作る
- **新ヒーロー・兄貴分の客演**：シリーズ途中の山場で、別のヒーローが助けに来る（例：『帰ってきたウルトラマン』第18話でウルトラセブンが登場）
- **最終回**：最強の宇宙怪獣にヒーローが敗れ、**人間側がとどめを刺す**（例：『ウルトラマン』最終回では、ゼットンにウルトラマンが敗れ、科学特捜隊の新兵器がゼットンを倒す）
  - → この企画の「親玉が勝ったら人間側で介入する」流れは、実際の名作の最終回と同じ構図になっている

### 割り振り案（決定）
| 話数 | 種類 | 内容 |
|---|---|---|
| 第1話 | **初回** | 企画書風タイトル → 怪獣が初めて街に降りる。電車ヌンチャクでそのまま操作を覚える（練習回を兼ねる）。終わると番組タイトルに変わる |

- 人間側プレイでも同じ13話の構成をそのまま使う

### 反響をシナリオに反映する
13話の骨組みは固定し、**各話の中身や次の話の展開が、視聴者の反響で変わる**ようにする。

- **反響の種類**：視聴率、怪獣人気、ヒーロー人気、苦情、ファンレター、SNSの話題、ソフビの売上 など
- **見せ方**：各話の終わりに「今週の反響」コーナー（視聴者のハガキ、SNSのトレンド、制作会議の様子）
- **シナリオへの反映例**
  - 怪獣人気が高い → 次の話で怪獣の出番が増える、再登場回が追加される、前後編に延長される
  - ヒーロー人気が高い → ヒーローが強化される、2号ヒーローの登場が早まる
  - 苦情が多い（壊しすぎ） → 脚本が変わって防衛隊が強化される、「被害を抑えて」と親玉から注意される
  - 視聴率が低い → 次の話がテコ入れ回になる（新キャラ、水着回のような特撮のお約束パロディ）
  - 総集編が続いた → 「今週も総集編」と苦情が来て、次の話が強制的に山場回になる
- **次回予告**も反響で変わる。予告と本編が違う、という特撮あるあるもネタにできる
  - 例：予告で大きく煽った展開（「新兵器登場！」「ついに決戦！」）が、本編では**5秒で終わる**
  - 予告ではすごそうだった新兵器が、怪獣のくしゃみ一発で壊れる。テロップ「新兵器、5秒で全損 / 損失 300億円」
  - 予告の煽りが大きいほど、5秒で終わったときの肩透かしが笑いになる
- 反響は人間側プレイにも引き継がれ、ヒーロー人気が奇跡の条件になる

### 劇中の反響とリアルの反響を混ぜる
反響には2つの層があり、**どちらが本当なのか分からない**ように混ぜて見せる。

- **劇中の反響**：怪獣に街を壊された市民・自治体・政府の反応（「電車を返して」「避難生活3か月目」）
- **リアルの反響**：特撮番組を見ている視聴者の反応（「今週の怪獣かわいい」「ミニチュアの出来がすごい」）
- 見せ方
  - 「今週の反響」コーナーで、2つを**区別せずに同じ枠で並べる**
  - どちらとも取れる声を多めにする（「電車返して」は被害者の声か、鉄道ファンの視聴者の声か）
  - たまに明らかにおかしいものが混ざる（視聴者のハガキに劇中の地名で被災報告が書いてある、劇中のニュースで番組の視聴率が報じられる）
- 最終回の「実は特撮番組でした」の種明かしで答え合わせ……**のはずが、答えをはっきりさせない**
  - 「カット！」の後、スタジオを出るとスタッフの通勤電車が運休している、などの小さな違和感を一つだけ残す
  - 番組だったのか、本当に起きたのか、プレイヤーに想像させて終わる
- **エンドロール後の最後の一場面**（決定）
  - スタッフのエンドロールが終わって画面が暗転
  - 静かになったところで、遠くから**轟音**
  - 窓の外（またはスタジオの外の街）に**煙**が上がり、ビルの向こうに**巨大な影**が一瞬だけ見える
  - 説明もテロップもなく、そのまま終わる
  - 影のシルエットは、**第1話（初回）の怪獣**の形。改造前の素の姿で、プレイヤーが最初に出会ったあの怪獣だと分かるようにする

## 決定：爽快感はミニゲーム、結果はニュース

### 1ターンの流れ
1. **コマンド選択**（パワポケ風）：朝・昼・晩の行動を選ぶ。体力と失敗率を確認
2. **ミニゲーム**：選んだ行動を自分で操作する。**爽快感はここで出す**（ジオラマの画、壊れる手応え、音、画面の揺れ）
3. **結果画面 = ニュース**：スコア画面をニュース番組の形にする
   - 能力の上昇、被害額、連鎖被害の明細をテロップと実況で伝える
   - 見つかっていない間は「うわさ・目撃情報」、見つかっていれば「速報・特番」と、枠が警戒度で変わる

### 「行動名だけ見せる」仕組みの調整
- ミニゲームで自分で壊すので、**何で何をしたかはプレイヤーに見える**
- 代わりに、**その後に何が起きたか（連鎖被害）はニュースで初めて分かる**ようにする
  - 例：電車ヌンチャクのミニゲーム → ニュースで「すっぽ抜けた車両が隣県の変電所に直撃、3県で停電」
- ミニゲーム中は怪獣の周りしか見えず、遠くの被害はニュースで知る、という見せ方にする
- 人間側プレイでの答え合わせは、「連鎖被害がどこで起きるか」を先読みして備える形になる
